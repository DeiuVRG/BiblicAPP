# M0 — Testable skeleton (technical product first)

Goal: ONE Expo codebase that runs on iOS, Android and web, reads real content offline from signed content packs, has the security baseline built in, and is built and tested on GitHub (web on GitHub Pages, Android APK as a build artifact). No accounts, no server, no payments, no AI in M0.

## Scope

1. Monorepo: pnpm 10 workspaces (`node-linker=hoisted` in `.npmrc`), Node 22, TypeScript strict everywhere, ESLint (`eslint-config-expo`) + Prettier, Vitest for packages, Jest (`jest-expo`) + React Native Testing Library for the app. Layout: `apps/mobile`, `packages/shared`, `packages/content-tools`, `content/` (sources and canonical work files), `supabase/` (migrations only, not applied in M0), `.github/workflows`, `docs/`, `scripts/`.
2. `apps/mobile`: Expo SDK 58 (React Native 0.88, New Architecture), Expo Router with typed routes, CNG (no `ios/` or `android/` committed), `app.config.ts`. Web output `static`; base path for GitHub Pages (`/BiblicAPP`) configurable at export time through an env variable. Screens: Library (works from installed packs), Work (table of contents), Reader (chapter view: paragraphs as native Text, left-aligned; font size, line height, theme light/dark/sepia; settings persisted; reading position per work persisted), Search (local, across installed packs), Settings/About. UI strings in Romanian through a tiny i18n module. Accessibility: font scaling respected, screen-reader labels, sufficient contrast. Reader font: a serif that covers U+0218–U+021B (ș/ț with comma), e.g. Literata via `@expo-google-fonts/literata`; UI font Inter.
3. Content model (`packages/shared`, Zod): `PackManifest` { packId, kind: 'edition', workId, editionId, revision, version, createdAt, sha256 (of pack.json bytes), size, minAppVersion, signingKeyId, signature (Ed25519, base64) } and `Pack` { work { id, slug, titleRo, titleOrig, author { name, born, died, tradition }, languageOrig, year }, edition { id, language, kind: 'source' | 'translation', licence { status: 'public-domain' | 'licensed' | 'unknown', note }, provenance { source, extractedBy, notes } }, sections [ { id, ordinal, kind: 'chapter' | 'section', heading, parentId? } ], paragraphs [ { id, sectionId, ordinal, kind: 'p' | 'heading' | 'quote' | 'note', text } ] }. Paragraph IDs are stable strings (ULID-like) generated once at ingest and never regenerated. Signature verification in the app with `@noble/ed25519` and `@noble/hashes`; TWO pinned public keys in app config (current + next); a dev keypair whose public key is committed and whose private key lives in `content/keys/` (gitignored) — the CI/signing key is replaced later.
4. `packages/content-tools` CLI (run with `tsx`): `ingest-text` (raw `pdftotext` output → cleaned canonical work JSON: drop running page headers via repetition heuristics, remove form feeds, dehyphenate line-end hyphens, join wrapped lines into paragraphs, detect chapter headings such as ALL-CAPS lines or `CHAPTER I`, drop front matter before the first chapter unless `--keep-front-matter`), `build-pack` (canonical JSON → `pack.json` + `manifest.json` with sha256 and Ed25519 signature), `verify-pack`, `keygen`. Unit tests for dehyphenation, paragraph joining, heading detection, sign/verify round-trip. Sample work: `content/sources/vos-1903-kingdom/raw.txt` (Geerhardus Vos, *The Teaching of Jesus Concerning the Kingdom of God and the Church*, 1903, English, public domain; OCR text layer from a scan) → `content/works/vos-1903-kingdom/` → built pack committed under `apps/mobile/assets/packs/vos-1903-kingdom-en/` because it is bundled in the app.
5. `ContentRepository` interface in the app with an in-memory JSON implementation for M0 (SQLite packs come in M1); the app verifies the bundled pack's manifest signature and sha256 at load and refuses to show an unverified pack.
6. `supabase/migrations/0001_init.sql` (written, reviewed, NOT applied in M0): schemas `public` (exposed) and `content` (not exposed); tables `licences`, `authors`, `works`, `editions`, `edition_revisions`, `sections`, `public.paragraphs` (metadata) and `content.paragraph_revisions` (text), `profiles`, `highlights`, `notes`, `bookmarks`, `reading_progress`, `entitlements` (service role only), `app_config`, `audit_log`; RLS deny-by-default with owner policies using `(select auth.uid())`; `REVOKE ALL ON SCHEMA content FROM PUBLIC, anon, authenticated`; `SECURITY DEFINER` RPC stubs `get_chapter`, `get_paragraphs` with fixed `search_path`; a `supabase/README.md` describing how to create the project in eu-central-1 and apply migrations; a pgTAP grant-allowlist test file.
7. Security baseline: no secrets anywhere; `.env.example` only; a script that fails CI if any `EXPO_PUBLIC_*` value looks like a secret; Dependabot (weekly, grouped); GitHub Actions with least-privilege `permissions`; pinned tool versions (Node, pnpm, Java); `pnpm audit --prod` in CI (moderate and above fails); pack signature verification; `docs/security.md` with the baseline checklist and what is deferred (auth, attestation, RLS at runtime).
8. GitHub Actions: `ci.yml` (push + PR: frozen install, typecheck, lint, Vitest, Jest, `expo export -p web`, Playwright smoke against the export), `web-pages.yml` (push to main: export with the Pages base path → `actions/upload-pages-artifact` → `actions/deploy-pages`; document that Pages must be enabled with source "GitHub Actions"), `android-apk.yml` (push to main and manual: Java 17, Android SDK, `npx expo prebuild -p android --no-install`, `./gradlew assembleRelease` with the template's debug signing for test builds, upload the APK as an artifact; on tags `v*` also attach it to a GitHub Release). iOS builds are out of scope in M0 (needs macOS runner and an Apple Developer account); the code must still run on iOS.
9. Tests: Vitest in packages; 2–3 Jest component tests in the app (reader renders paragraphs of the sample pack; settings persist; signature failure hides the pack); `scripts/smoke-web.mjs` Playwright smoke that serves `apps/mobile/dist` and checks that the library lists the sample work and the reader shows its first chapter.
10. Docs: this spec, `docs/decizii.md` (ADR list: JSON packs in M0 and SQLite in M1; GitHub Pages subpath; debug-signed test APK; no Expo Go), `README.md` with run instructions.

## Out of scope in M0

Auth, Supabase at runtime, payments, AI, the Astro public site, the admin app, Bible texts, EAS, iOS builds, analytics.

## Definition of done

`pnpm install --frozen-lockfile && pnpm -r typecheck && pnpm -r lint && pnpm -r test && pnpm --filter mobile export:web` pass locally; the Playwright smoke passes on the export; workflow YAML is valid; everything is pushed to `main` and the GitHub Actions runs are green (web deployed, APK artifact produced).
